# AI-Agents
This AI-powered email reply agent is an automated workflow built using n8n  and Google Gemini  that helps users manage and respond to emails intelligently.

# Project Description
The system automatically checks incoming Gmail messages at scheduled intervals, reads the email content, generates an AI-based response using the Gemini language model, marks the email as read, and sends the generated reply back to the sender. This reduces manual effort and improves communication efficiency.

# Key Features
Automated email monitoring using Gmail API
AI-generated smart replies with Google Gemini
Scheduled execution for continuous monitoring
Automatic marking of processed emails as read
Seamless email response sending
Fully automated workflow using n8n automation platform

# Workflow Process
The Schedule Trigger starts the workflow daily at a fixed time.
Gmail retrieves recent unread messages.
The system fetches the complete email content.
The AI Agent analyzes the message and generates a contextual reply using Gemini AI.
The processed email is marked as read.
The generated response is automatically sent back through Gmail.
